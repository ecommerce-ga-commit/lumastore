# Luma Cart — GA4 + GTM Demo Ecommerce Website

A small, GitHub Pages-friendly ecommerce website created for testing Google Tag Manager (GTM), GA4, and a structured `dataLayer`.

## Important User-ID implementation note

Google recommends User-ID as a persistent, unique, non-personally-identifiable identifier for signed-in users. This demo therefore sends:

- `user_id: null` for guests
- a generated stable demo ID such as `UID_...` after login
- `user_type: 'guest'` or `user_type: 'loggedin'`
- `page_type` on every page

The generated ID is stored in `localStorage` only for demo purposes. In a real ecommerce website, replace the demo login logic with the authenticated customer ID generated by your backend/CRM. Do not use an email address, mobile number, name, or other PII as the GA4 User-ID.

## Where the initial dataLayer code lives

Each HTML page contains the initialization directly after the `<head>` tag opens and before the GTM loader block:

```html
<script>
  window.dataLayer = window.dataLayer || [];
  window.dataLayer.push({
    user_id: localStorage.getItem('luma_logged_in') === 'true'
      ? localStorage.getItem('luma_user_id')
      : null,
    user_type: localStorage.getItem('luma_logged_in') === 'true' ? 'loggedin' : 'guest',
    page_type: 'homepage'
  });
</script>
```

Only the `page_type` value changes per page.

## GTM setup

1. Replace `GTM-XXXXXXX` in every HTML file with your actual Google Tag Manager container ID.
2. Publish the site on GitHub Pages.
3. In GTM Preview/Tag Assistant, confirm the initial data layer values appear before your Google tag fires.
4. Create Data Layer Variables for:
   - `user_id`
   - `user_type`
   - `page_type`
   - `pageName`
   - `mainMenuCategory`
   - `mainMenuSubCategory`
   - `mainMenuTab`
   - `headerLink`
   - `headerLinkPosition`
   - `searchTerm`
   - `searchResult`
   - `searchType`
   - `suggestedTerm`
   - `searchSuggestionPosition`
   - `footerLink`
   - `footerLinkPosition`
   - `footerSection`
5. Create Custom Event triggers for:
   - `menuClick`
   - `headerClick`
   - `search`
   - `searchSuggestionClick`
   - `footerClick`
   - `login_success`
   - `logout`

For the GA4 event tags, use the exact custom event name as the GA4 Event Name and map the corresponding data layer values to event parameters. For example, the `search` GA4 event can pass `searchTerm`, `searchResult`, and `searchType`.

## GitHub Pages deployment

Upload the folder contents to a GitHub repository, then open:

`Settings → Pages → Deploy from a branch`

Choose the branch containing these files and the `/ (root)` folder. GitHub Pages will publish `index.html` as the homepage.

## Pages included

- `index.html` — homepage with main navigation, header links, search, product cards, and footer
- `products.html` — product listing/search results
- `product.html?id=1` — product detail page
- `login.html` — demo login that generates/persists a stable demo User-ID
- `account.html` — shows the current login state and User-ID, with logout
- `404.html` — simple GitHub Pages fallback page

## Event examples

### Menu click

```js
dataLayer.push({
  event: 'menuClick',
  pageName: 'homepage',
  mainMenuCategory: 'Shop',
  mainMenuSubCategory: 'Apparel',
  mainMenuTab: 'New Arrivals'
});
```

### Header click

```js
dataLayer.push({
  event: 'headerClick',
  headerLink: 'account',
  headerLinkPosition: 'right',
  pageName: 'homepage'
});
```

### Search

```js
dataLayer.push({
  event: 'search',
  searchTerm: 'linen',
  searchResult: 2,
  searchType: 'text',
  pageName: 'homepage'
});
```

### Search suggestion click

```js
dataLayer.push({
  event: 'searchSuggestionClick',
  suggestedTerm: 'Linen Everyday Shirt',
  searchSuggestionPosition: 1,
  pageName: 'homepage'
});
```

### Footer click

```js
dataLayer.push({
  event: 'footerClick',
  footerLink: 'Shipping',
  footerLinkPosition: 2,
  footerSection: 'Useful Links',
  pageName: 'homepage'
});
```
